네이버 카페 자동 포스팅 사용 설명서

구글 시트에 적힌 일정대로 카페 글을 자동으로 올리는 프로그램입니다. 이 문서는 대시보드(프로그램 화면)를 기준으로, 처음 쓰는 분도 따라 할 수 있게 정리했습니다.

처음 켜기

실행 파일만 켜면 업데이트, 시트 불러오기, 예약 모드 켜기까지 자동으로 진행됩니다.

  1. NaverCafeAuto.exe를 실행합니다.
    새 버전이 있으면 묻지 않고 받아서 다시 켜집니다. 잠시 기다리면 됩니다.
  2. 작업 목록이 자동으로 불러와집니다.
    로그 창에 대기중: N개, 예약됨: N개, 완료됨: N개 불러오기 완료가 보이면 준비가 끝난 것입니다.
  3. 예약 모드가 자동으로 ON(초록)이 됩니다.
    이 상태로 켜 두면 1분마다 시트를 확인해서 예약 시각이 된 글을 올립니다.
예약 모드는 PC 한 대에서만 켜 두세요

두 대 이상에서 ON이면 같은 아이디 브라우저가 서로 충돌하거나 글이 겹쳐 올라갈 수 있습니다. 업로드 담당 PC가 아니라면 OFF를 누르세요. 시트 불러오기를 누를 때마다 다시 ON으로 바뀌므로, 불러온 뒤에는 OFF를 다시 눌러야 합니다.

프로그램이 켜져 있어야 올라갑니다

업로드 PC는 절전 모드로 들어가지 않게 해 주세요. 꺼져 있는 동안 지나간 예약은 다음에 켰을 때 바로 올라갑니다.

표의 칸

선택 · 번호(시트 A열) · 이름 · 아이디 · 포트 · 카페명 · 게시판 · 업로드 · 다음예약. 업로드 칸은 대기중 표에서는 전체 주기(예: 2주,1달,3달), 예약된 표에서는 이번에 올릴 차수의 주기(예: 1달)를 보여줍니다. 칸 제목을 누르면 그 기준으로 정렬되고, 예약이 있는 줄을 우클릭하면 예약 취소 메뉴가 나옵니다.

매일 확인할 것

업로드 담당자는 하루 한두 번 아래 세 가지만 보면 됩니다.

예약 모드가 초록 ON인가

OFF(빨강)이면 아무것도 올라가지 않습니다.

대기중 표 위에 빨간 글씨가 있나

🔒 캡챠나 ⚠ N차 에러가 보이면 경고 대처법대로 처리합니다.

업로드 칸이 빨간 배경인가

글 파일이 없다는 뜻입니다. 파일 준비를 확인하세요.

자주 하는 작업

대부분 대시보드에서 끝납니다. 시트를 직접 고쳤다면 마지막에 시트 불러오기를 누르세요.

새 작업 예약하기

  1. 구글 시트에 한 줄을 추가합니다. 이름, 아이디, 비밀번호, 카페명, 게시판, 업로드 주기, 파일 위치를 채웁니다. (칸 안내)
  2. 시트 불러오기를 누르면 대기중인 작업 표에 나타납니다.
  3. 그 줄의 다음예약 칸을 더블클릭합니다.
  4. 달력에서 첫 글을 올릴 날짜와 시간을 고릅니다. 달력에 날짜별 예약 건수가 보이니 붐비는 날은 피하세요.
  5. 설정 완료 (OK)를 누르면 1차 시각이 시트에 적히고, 2~4차는 주기에 맞춰 자동으로 계산됩니다(오전 10시~오후 8시 사이 임의 시각). 작업은 예약된 작업 표로 옮겨집니다.

예약 시간 바꾸기

예약된 표에서 다음예약 칸을 더블클릭해 새 시간을 고릅니다. 이번 차수 이후의 일정도 새 시간을 기준으로 다시 계산됩니다.

지금 바로 올리기

대기중 또는 예약된 표에서 체크하고 작업 시작을 누릅니다. 진행 상황은 로그 창에 나옵니다.

예약 취소

여러 개는 체크 후 예약 취소 버튼, 하나는 그 줄을 우클릭해 예약 취소. 날짜가 지워지고 대기중으로 이동합니다.

끝난 작업 다시 시작

완료된 표에서 체크 → 선택한 작업 리셋. 1~4차 일정이 비워지고 대기중으로 돌아가면, 새 작업처럼 다음예약을 더블클릭해 1차를 잡습니다. 따로 하지 않아도 마지막 업로드 90일 뒤에는 자동으로 리셋·재예약됩니다.

미리 로그인해 두기

⑥ 사전 로그인에서 아이디를 고르고 브라우저 열기 → 로그인 상태 유지가 체크된 채로 로그인 버튼을 누릅니다. 로그인 후 창은 닫아도 됩니다.

경고가 떴을 때

경고는 대기중 표 제목 옆에 빨간 글씨로 나옵니다. 빨간 글씨에 마우스를 올리면 행 번호·이름·카페·에러 내용이 전부 보입니다.

🔒 캡챠-수동로그인 필요

네이버가 자동 로그인을 막으려고 글자 입력(캡챠)을 띄운 상태입니다. 사람이 한 번 직접 로그인해 주면 풀립니다. 같은 아이디는 팝업도 하나만 뜹니다.

  1. 제목 옆 빨간 버튼 🔑 정우철(대현) 로그인하러 가기를 누릅니다. 여러 명이면 목록에서 고릅니다. (이름 글씨를 누르면 표에서 그 줄로 이동합니다.)
  2. 열린 크롬 창에 아이디·비밀번호가 이미 들어가 있습니다. 캡챠 글자를 입력하고 로그인 버튼을 누릅니다.
  3. 끝입니다. 프로그램이 로그인을 알아채고 빨간 표시와 시트 에러를 자동으로 지웁니다(최대 60분까지 지켜봅니다). 업로드 중에 막혔던 일정은 원래 예약 시각으로 되돌아가며, 그 시각이 이미 지났다면 1분 안에 바로 올라갑니다.

로그인을 마치기 전에 크롬 창을 닫지 마세요. 캡챠 실패 목록은 시트 O1 칸에도 적혀 담당자에게 메일로 알림이 갑니다.

캡챠가 뜬 아이디는 계정 보호조치를 막으려고 프로그램이 스스로 다시 로그인하지 않습니다. 직접 로그인해 주기 전까지는 업로드도 되지 않으니 경고가 보이면 되도록 빨리 처리해 주세요.

⬆ 등업 필요 (1건): 수성97(카페명)

그 카페에서 아이디의 등급이 모자라 게시판에 들어가지 못한 작업입니다. 등급은 다시 해도 바뀌지 않으므로 재시도 없이 바로 멈춥니다. 대기중 표의 다음예약 칸에는 주황 배경으로 ⬆ 등업 필요: 중급 발품사전 (현재 새싹 발품)처럼 필요한 등급이 나오고, 마우스를 올리면 네이버 안내 문구 전체가 보입니다.

  1. 그 카페의 등업 조건(게시글·댓글 수, 방문 수, 가입 기간 등)을 채워 필요한 등급으로 올립니다. 조건은 카페의 등급 안내에 나옵니다.
  2. 등업이 되면 다음예약 칸을 더블클릭해 새 시간을 잡습니다. 그때부터 다시 올라갑니다.

⚠ 1차 에러 (1)  2차 에러 (4) …

같은 작업이 세 번(첫 실패 → 10분 뒤 → 30분 뒤) 실패해서 시트의 일정 칸에 에러(시각): 사유가 적힌 건수입니다. 해당 줄의 다음예약 칸에도 빨간 글씨로 사유가 나옵니다. 원인을 고친 뒤 다음예약 칸을 더블클릭해 새 시간을 잡으면 다시 예약됩니다.

프로그램 실행 시최신 버전으로 자동 업데이트합니다.

자주 묻는 질문

현장에서 많이 나온 질문입니다.

다른 PC에서 화면만 보고 싶어요.

켜도 됩니다. 단, 켜자마자 예약 모드를 OFF로 바꾸세요. 시트 불러오기를 누르면 다시 ON이 되니 그때마다 OFF를 눌러야 합니다.

시트를 고쳤는데 화면이 그대로예요.

시트 불러오기를 누르세요. 화면은 자동으로 새로 고쳐지지 않습니다(업로드가 끝난 직후 제외).

사전 로그인 후 크롬 창을 닫아도 되나요?

로그인을 마쳤다면 닫아도 됩니다. 아이디마다 따로 저장된 크롬 프로필에 로그인 상태가 남습니다. 캡챠 경고로 연 창은 로그인을 끝내기 전까지 닫지 마세요.

포트 번호는 뭔가요? 바꿔야 하나요?

아이디별 크롬 창을 구분하는 번호로, 자동으로 정해집니다. 바꿀 필요가 없습니다.

작업 시작을 눌렀는데 아무 반응이 없어요.

체크한 작업이 없으면 '선택된 작업이 없습니다' 경고가 뜹니다. 예약 업로드가 진행 중이면 한 번에 하나씩 처리하므로 끝날 때까지 기다렸다가 시작됩니다. 로그 창을 확인하세요.

업데이트 후 'Failed to load Python DLL' 창이 떠요.

아주 예전 버전(v1.32 이하)에서 올라올 때 한 번 생길 수 있습니다. 확인을 누르고 프로그램을 다시 실행하면 됩니다.
