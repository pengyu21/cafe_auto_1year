변경 내용:
- 예약 모드에서 업로드 24시간 전에 해당 아이디의 브라우저를 미리 열어 사전 로그인 상태를 확인 (아이디별 12시간마다 재확인)
- 로그인이 풀려 있으면 시트의 비밀번호로 자동 로그인 시도 ('로그인 상태 유지' 체크)
- 캡챠/기기 인증 등으로 자동 로그인에 실패하면 브라우저를 로그인 화면에 띄워두고 팝업으로 알림 → 직접 로그인하면 업로드 때 그대로 사용
- 업로드 시 로그인이 풀려 있으면 그 자리에서 사전 로그인(자동 로그인)을 다시 하고 바로 업로드 진행
- 로그인 후 '새로운 기기 등록'/로그인 정보 저장 화면이 뜨면 자동으로 '등록(저장)' 클릭
- 바뀐 네이버 로그인 화면(로그인 상태 유지·로그인 버튼) 대응
