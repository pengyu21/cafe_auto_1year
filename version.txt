현재 버전: v1.42
업데이트 날짜: 2026-10-26
다운로드: https://github.com/pengyu21/cafe_auto_1year/releases/latest

변경 내용:
- 캡챠 경고를 누구인지 바로 알 수 있게 개선
  - 대기중 표 위 경고에 건수 대신 이름을 바로 표시 (예: '🔒 캡챠-수동로그인 필요 (1명): 정우철(대현)'), 이름을 누르면 표에서 그 행으로 이동
  - 캡챠 건수를 아이디(사람) 기준으로 셈: 사전 로그인 캡챠와 업로드 캡챠 에러가 같은 사람이면 1명으로 표시 (기존엔 2로 표시됨)
  - 캡챠 에러는 '1차 에러' 같은 단계별 에러 건수에서 제외 (같은 건이 두 번 세지던 문제)
  - 표의 캡챠 행은 이름 칸도 빨간 글씨(🔒)로, 다음예약 칸은 '🔒 캡챠-수동로그인 필요 (에러 시각)'으로 짧게 표시 (전체 내용은 마우스를 올리면 확인)
  - '로그인하러 가기' 버튼에 누구인지 표시 ('🔑 정우철(대현) 로그인하러 가기', 여러 명이면 '🔑 정우철(대현) 외 1명 로그인하러 가기')
- 사전 로그인 브라우저를 열면 로그인 화면에 시트의 아이디/비밀번호를 자동으로 입력하고 '로그인 상태 유지'를 체크해 둠
  - 로그인 버튼은 누르지 않으므로 캡챠가 있으면 풀고 직접 로그인 버튼만 누르면 됨
  - 시트 O1 캡챠 목록에서도 같은 사람이 두 번 기록되지 않게 함
- 시트 O1(메일 알림) 캡챠 목록에 엉뚱한 사람 이름이 적히던 문제 수정: 사전 로그인 캡챠 뒤 시트 행이 바뀌면 그 행에 있는 다른 사람으로 기록되던 것을 아이디로 찾도록 변경

전체 변경 내역: https://github.com/pengyu21/cafe_auto_1year/blob/main/CHANGELOG.md
